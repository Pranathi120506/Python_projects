# 🐍 Python Projects

Welcome to my Python Projects Repository!

This repository contains a collection of Python projects developed to improve my programming skills, explore different technologies, and gain hands-on experience in real-world application development.

The projects are organized into three levels: Beginner, Intermediate, and Advanced.

## 📂 Projects Included

### 1. TaskFlow – Smart To-Do List & Productivity Manager
**Level:** Beginner

A Python-based productivity application that helps users organize and manage their daily tasks.

**Features:**
- Add, update, and delete tasks.
- Set task priorities and deadlines.
- Track completed and pending tasks.
- Search and organize tasks.
- Generate task progress reports.

**Technologies:** Python, JSON, OOP, Datetime.

### 2. TaskHub – Full-Stack Task Management System
**Level:** Intermediate

A web-based task management application that allows users to manage their activities through an interactive dashboard.

**Features:**
- User registration and login.
- Create, update, and delete tasks.
- Task priority management.
- Kanban board for task tracking.
- Dashboard with task analytics.
- Database integration.

**Technologies:** Python, Flask, SQLite, HTML, CSS, JavaScript, REST API.

### 3. DocuMind – AI-Powered PDF Question Answering System
**Level:** Advanced

An AI-powered document assistant that allows users to upload PDF documents and ask questions based on their content.

**Features:**
- Upload and process PDF documents.
- Ask questions about uploaded documents.
- Generate document summaries.
- Generate quizzes and important questions.
- Retrieve relevant information using semantic search.
- Display answers with supporting page references.

**Technologies:** Python, Streamlit, RAG, LLM, Embeddings, FAISS.
